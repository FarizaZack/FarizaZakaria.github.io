01 About

Curiosity about the repetitive parts pulled me from accounting into automation.

I started out in finance and accounting. A lot of my early work was the usual routine: reports, reconciliations, and month-end tasks that came around again and again.

After a while I got curious about the repetitive parts. If I was copying the same numbers every month, there was probably a simpler way to do it, so I started looking for one.

That curiosity gradually pulled me into data analytics, automation, and building small internal tools. I wasn't trying to become a software developer. I just wanted to find better ways of doing everyday work.

These days I mostly build small internal tools. Nothing fancy. Just practical things that save people time, cut down on manual work, and actually get used.

02 Selected work
2.1

Revenue Assurance Pipeline

Python · DuckDB SQL · pandas · pytest

Problem
Billing information comes from different sources, making it difficult to spot missing invoices, duplicate charges or incorrect billing. Not every mismatch is an actual error.
Solution
Built a Python and SQL pipeline using synthetic billing data to compare records from nine sources, check for inconsistencies and flag items that need further review.
Value
Helps identify possible billing issues earlier, reduces unnecessary checks and makes it easier to understand why each item was flagged. The process is repeatable and tested with 25 automated tests.

🔒 Private repository | Source code not publicly available

2.2

Credit Card Fraud Detection

R · RMarkdown

Problem
Fraudulent transactions hide inside large volumes of card data and are hard to catch by eye.
Solution
Exploratory analysis that profiles transactions by customer behaviour, age, and location to highlight suspicious patterns.
Value
Shows how straightforward data exploration can flag the transactions worth a closer look.
